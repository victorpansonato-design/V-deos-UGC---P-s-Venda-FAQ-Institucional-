# Estudo ilustrado de rematrícula

Ensaio de 12 s em 9:16. Primeiro um calendário ganha um círculo manuscrito. Entre 4,50 s e 6,33 s entra um plano de campus de 55 quadros. Um documento com assinatura ilustrada conclui o recorte. O estudo é mudo e avalia estilo, leitura e duração da passagem.

A partir da raiz, com Node, FFmpeg e a mídia local autorizada. Prepare o MP4 com o início da tomada já selecionado e ao menos 1,84 s de imagem. Use um trecho sem cortes internos.

```sh
npm ci
npm run motion:check -- ilustrado acervo/campus/take-campus.mp4
npm run motion:render -- ilustrado acervo/campus/take-campus.mp4
```

A saída é `motion-ilustrado.mp4`. O plano do campus e a saída permanecem locais. Para a direção completa e o teste com locução, abra [direção ilustrada](../../docs/recuperacao/direcao-ilustrada.md).
